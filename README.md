# تحدي الأذكياء 🧠⚡

موقع مسابقات عربي تفاعلي بأسلوب برامج التلفزيون: ثماني مراحل، ٤٨ سؤالًا افتراضيًا، مؤقت لكل سؤال، نقاط ومكافآت، ولوحة متصدرين.

## المزايا

- **٨ مراحل متنوعة:** اختيار من متعدد، صح أو خطأ، اكتشف الخطأ، خمّن الصورة، رتّب الجملة، ألغاز، سباق الثواني، والسؤال المفاجئ بنقاط مضاعفة.
- **نظام نقاط كامل:** نقاط أساسية + مكافأة وقت + مكافأة سلسلة، وخصم عند الخطأ أو انتهاء الوقت.
- **مؤقت دائري** لكل سؤال مع تحذير بصري في الثواني الأخيرة، وعدم كشف الإجابة قبل اختيار اللاعب.
- **مؤثرات صوتية** مُركّبة داخل المتصفح (Web Audio API) بدون ملفات خارجية: صح، خطأ، سلسلة، تصفيق واحتفال.
- **نتائج تفصيلية:** المجموع، الصحيح/الخطأ، الدقة، أفضل سلسلة، تقييم بالنجوم، ومراجعة كل سؤال.
- **لوحة متصدرين** وأفضل نتيجة لكل مرحلة محفوظة محليًا.
- **محرر أسئلة كامل:** إضافة، تعديل، حذف، بحث وتصفية، تصدير واستيراد JSON، واستعادة الافتراضي.
- **شاشة عرض:** وضع ملء الشاشة، اختصارات لوحة المفاتيح، وتصميم متجاوب للجوال والحاسب.
- **عربي بالكامل** مع اتجاه RTL، وحفظ تلقائي في `localStorage`.

## التشغيل محليًا

لا يحتاج الموقع إلى أي أدوات بناء. افتح `index.html` مباشرة، أو شغّل خادمًا محليًا:

```bash
python -m http.server 8765
```

ثم افتح: `http://127.0.0.1:8765/`

## بنية المشروع

```
index.html          الصفحة الرئيسية وكل الشاشات
css/style.css       الأساس، الخلفية، البداية، المراحل
css/quiz.css        شاشة اللعب والنتائج
css/editor.css      المحرر، النوافذ، التنبيهات
css/responsive.css  نقاط التجاوب
js/data.js          المراحل الافتراضية و٤٨ سؤالًا
js/app.js           منطق اللعبة الكامل
```

## ملاحظات

- الأسئلة المعدّلة والنتائج تُحفظ في متصفح اللاعب فقط (`localStorage`)، ولا تُرسل إلى أي خادم.
- يمكن استبدال الخطوط الخارجية بخطوط النظام تلقائيًا عند انقطاع الإنترنت.
